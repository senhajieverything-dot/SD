## 1. PSD Layer Order Fixed

**File:** `core/psd_builder.py`

**Problem:** When opening the output PSD, the layer stack was:
1. Cleaned picture (top)
2. Original picture (middle)
3. Text folder (bottom)

**Fix:** Reversed the addition order. `PhotoshopAPI.add_layer()` places the first-added layer at the top, so the text group is now added first, then Cleaned Background, then Original.

**New layer stack (top to bottom):**
1. **Editable Text** group (top)
2. **Cleaned Background** (middle)
3. **Original** (bottom, optional)

## 2. All Layers Now Have 100% Fill & Opacity

**File:** `core/psd_builder.py`

**Problem:** Every layer in the PSD opened with 0% Fill, requiring manual adjustment to 100% for each layer.

**Fix:** Set `fill = 1.0` and `opacity = 1.0` on all three layer types:

- **Text layers** (`TextLayer_8bit`): Set after `text_group.add_layer(doc, layer)`
- **Cleaned Background** (`ImageLayer_8bit`): Set before `doc.add_layer(clean_layer)`
- **Original** (`ImageLayer_8bit`): Set before `doc.add_layer(orig_layer)`
